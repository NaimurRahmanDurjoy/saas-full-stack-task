## 📋 Submission Overview

The assessment tasks have been divided into specific directories for clear separation of concerns, culminating in a complete, robust Full-Stack SaaS application.

### 1️⃣ [Task 1: React Frontend Development](./task-1-react)
This directory contains the initial frontend-focused task. It demonstrates proficiency in React, component structuring, state management, and modern UI/UX design implementation.

### 2️⃣ [Task 2: Laravel Backend API](./task-2-laravel)
This directory contains the backend-focused task. It showcases API development using Laravel, routing, request validation, authentication, and core business logic implementation.

### 3️⃣ [Task 3: Database Architecture](./task-3-database)
This directory focuses on relational database design. It contains the schema modeling required for a multi-tenant SaaS application, including product variants, categories, and subscription handling.

### 🌟 [Final Integrated Project: E-Commerce SaaS Platform](./ecommerce-saas)
**The core deliverable of this submission.** This directory contains the fully integrated, production-ready Multi-Tenant E-Commerce SaaS platform combining the frontend, backend, and database architectures from the previous tasks.

**Key Highlights of the SaaS Platform:**
- **Platform Admin Panel:** Centralized dashboard for managing the SaaS platform.
- **Tenant Merchant Dashboard:** Where store owners manage products, variants, orders, and sales reports.
- **Premium Storefront:** A visually stunning, glassmorphic customer-facing UI built with React and Framer Motion.
- **Architecture:** API-driven headless approach using React (Vite) and Laravel Sanctum (Inertia was purposefully avoided to strictly separate concerns).
