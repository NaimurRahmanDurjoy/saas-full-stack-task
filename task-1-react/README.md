# Task 1 - React User Directory

This is a standalone React application built using Vite for the Junior SaaS Full-Stack Engineer take-home assignment.

## Features
- Fetches users from the JSONPlaceholder API.
- Displays a clean, responsive user grid.
- Proper loading state management.
- Proper error state handling.
- Built using functional components and React hooks (`useState`, `useEffect`).

## Requirements Met
- React with Vite
- Functional components
- `useEffect` and `useState` hooks
- Loading and error states
- Clean UI & responsive design

## Setup Instructions

1. Make sure you have Node.js installed.
2. Open your terminal and navigate to this folder (`task-1-react`).
3. Install dependencies by running:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open the displayed local URL in your browser (usually `http://localhost:5173`).

## Build for Production
To create a production build, run:
```bash
npm run build
```
